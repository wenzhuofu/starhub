# 用工具架

工具架里是用户在 GitHub 上 star 过的项目。每一个都写好了“是什么、什么时候用得上”，有的带可以直接加载的 skill。

## 步骤

1. 读 `~/.starhub/tools/INDEX.md`。它很短，每行是一个工具：`仓库 [类型·状态] 是什么 → 何时用 ⚔冲突`。
   - 选 0 到 3 个；状态是 active 或 trial 的优先。
   - 带 ⚔ 的同一组只选一个，并说明理由。
   - 都不合适就直说，不要硬套。
2. 对每个候选运行 `starhub show <仓库> [关键词]`，看依赖、注意事项，以及其中每个 skill 的说明和路径。
3. 用一两句话告诉用户选了哪个、为什么。
4. 用起来：
   - **skill 类**：还没拉取的，先运行 `starhub vendor <仓库>`。然后只读选中的那一个 SKILL.md，照着做；它带的脚本用绝对路径调用。
   - **需要安装的工具**：把 `setup` 里的命令给用户看，同意后再装。
5. 用完运行 `starhub log <仓库> "<任务> · 好/一般/差 · 原因"`。
